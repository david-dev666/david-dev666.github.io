# david-dev-lab.github.io

个人主页与技术博客，聚焦 VLM 多模态技术。

## 技术栈

Astro + Tailwind CSS + KaTeX

## 本地开发

```bash
npm install
npm run dev
```

## 配置

编辑 `src/config.ts` 修改个人信息、项目展示等内容。

## 部署

推送至 `main` 分支，通过 GitHub Pages 自动部署。

## 写作规范

### Notes 的「811 原则」

每一篇 `notes/` 目录下的文章，内容配比遵循：

- **80%** 知识与原理：硬核技术内容，概念、机制、公式、推导、工程权衡
- **10%** 个人思考：基于实践经验的反思、判断、取舍
- **10%** 方法论 / 结构性收尾：可复用的决策框架、checklist、铁律

**目的**：让每一篇 notes 都是一份**能让读者学到东西的技术资料**，而不是个人情绪或流水账。思考和方法论不是主角，但必不可少 —— 它们是把知识点"粘合"成可迁移经验的胶水。

### 其他约束

- 中英文、公式与文字之间不加空格
- 数学符号加粗用 `\boldsymbol{}`
- 涉及业务的信息必须脱敏；`personal/` 目录在 gitignore 内，仅作为本地素材箱
