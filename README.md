# david-dev-lab.github.io

深度学习手记 —— 视觉语言模型与深度学习的技术博客。

## 内容

围绕 VLM 多模态方向，记录原理、工程实践与踩坑：

- **Notes** — 系统的技术长文，讲清机制、公式与工程权衡
- **Essays** — 短篇随笔，对方法与实践的思考
- **Paper Reading** — 经典论文精读
- **Dictionary** — 术语词典，聚焦常被问到的关键概念
- **Quiz** — 选择题自测
- **Q&A** — 常见问题整理

## 技术栈

Astro + Tailwind CSS + KaTeX

## 快速开始

```bash
npm install
npm run dev        # 本地预览
npm run build      # 构建产物到 dist/
```

## 配置与部署

编辑 `src/config.ts` 修改个人信息与项目展示；推送 `main` 分支后由 GitHub Pages 自动部署。
