## 组内优势

对同一问题采样 $G$ 条回答，奖励记为 $r_1,\ldots,r_G$。GRPO 的组内优势通常写为：

<div class="math-block">

$$A_i = \frac{r_i - \bar r}{\sigma_r + \epsilon}$$

</div>

其中，$\bar r$ 为组内均值，$\sigma_r$ 为组内标准差，$\epsilon$ 用于避免除零。使用 outcome reward 时，同一回答中的 token 通常共用该优势值。基本形式见 [DeepSeekMath 论文](https://arxiv.org/abs/2402.03300)。

## 全同奖励

组内奖励完全相同时，$r_i-\bar r=0$，所有优势均为零。该组不提供回答之间的相对奖励信号。目标中的 KL 等其他项仍可能产生梯度。

二值正确性奖励下，全对和全错均属于全同奖励组。[DAPO](https://papers.nips.cc/paper_files/paper/2025/file/a4277440d50f1f15d2cb4c14f7e0c0d2-Paper-Conference.pdf) 的 Dynamic Sampling 通过过采样，过滤准确率为 0 或 1 的 prompt，保留组内有对有错的样本。这会增加采样开销；其他奖励设定需要重新确定过滤条件。

## 奖励尺度

忽略 $\epsilon$，按总体标准差计算，两组奖励及其优势为：

`[0.79, 0.80, 0.80, 0.81]` → `[-1.41, 0, 0, 1.41]`  
`[0.20, 0.50, 0.50, 0.80]` → `[-1.41, 0, 0, 1.41]`

两组奖励的差距相差 30 倍，归一化后的优势相同。标准差归一化消除了组内差异的绝对尺度，微小差异也可能对应较大的优势值。

差异能稳定反映回答质量时，归一化保留有效的相对信号；差异来自评分噪声时，噪声也会被缩放。组内标准差只能描述差异大小，不能单独判断信噪比。奖励可靠性还需要结合评分稳定性和重复采样时的排序一致性判断。

## 训练中的检查

分析优势时，同时记录原始奖励和以下统计量：

- **平均奖励**：反映题目对当前策略的难度。
- **组内标准差**：描述同一问题下回答的奖励差异。
- **全同奖励组占比**：反映缺少组内相对信号的样本组比例。

根据观察结果分别处理：

- **全同奖励组过多**：二值奖励下，可调整题目难度或采用过采样过滤。
- **奖励差异非零但很小**：检查评分精度和稳定性。直接按标准差阈值过滤，可能丢弃有效信号。
- **回答多样性不足**：可增加 group size 或调整采样温度，并观察排序稳定性的变化。
- **调整归一化方式**：Dr. GRPO 等方法只减去组内均值，不再除以标准差。此时，组内奖励差距越大，优势的绝对值也越大；在其他条件相同时，这些样本对策略更新的影响更大。全同奖励组的优势仍然为零。
